## Repo Structure

## Workflow for New Job Applications
1. User provides a job posting (URL or text)
2. **Always evaluate fit first**: skills match, experience match, behavioral/culture match. Present this assessment to the user before proceeding.
3. If good fit: create targeted CV (`cv/main_<company>_<role>.tex`) and cover letter (`cover_letters/cover_<company>_<role>.tex`)
4. **Verify both documents** (see Verification Checklist below; the checklist itself is loaded only at this point)
5. Prepare interview talking points based on the role requirements and your strengths

**Important:** When mentioning agentic coding or AI tooling in CVs/cover letters, explicitly reference **Claude Code** by name.

## Verification Checklist
After creating or updating a CV or cover letter, load `.claude/skills/job-application-assistant/10-verification-checklist.md` and report every item there as a pass/fail checklist before presenting the result. Compiling both PDFs and reading them is mandatory; "looks fine in the .tex" is not acceptable.
